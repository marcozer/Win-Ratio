# Reviewer FAQ

## Why is the committed dataset synthetic?

Because the protected registry export contains direct and indirect disclosure risks that are not suitable for a public GitHub repository.

## Does the package still reflect the study's statistical method?

Yes. The public package exposes the same core analytical machinery used in the study: ordered pair comparisons, propensity-score matching, matched analyses, cluster bootstrap, and inference helpers.

## What is directly reproducible from the public repository?

The public study workflow, synthetic-data example outputs, configuration loading, and the full generic package behavior are reproducible without protected data.
